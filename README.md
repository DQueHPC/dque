# DQueHPC releases

This is the public binary distribution repository for DQueHPC v3. Product
source is maintained separately. Immutable `v3.x.y` GitHub Releases contain
the native server bundle, portable `dque` clients, build metadata, checksums,
and detached signatures.

The reviewed bootstrap and pinned artifact-signing public key are added through
normal pull requests. No private source, artifact-signing private key, license
issuer key, customer license, or deployment secret belongs in this repository.
